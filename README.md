# Astro9

Final Project for UC Berkeley ASTRO 9 LEC 002 (Python for Astrophysics Research) - On the Search for a New Earth

View the project with sample data here: https://astro9exoplanets.streamlit.app/

## Instructions to run locally: 

Download all files and folders

Run the command "streamlit run app.py" in the terminal

Process:
1. Smoothed TPF using a rolling average
2. Applied transit least squares fitting
3. Used physics and other inputted values to check for habitability
